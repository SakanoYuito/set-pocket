# SET Pocket

Android のホーム画面で SET を練習する Kotlin 製ウィジェット。Android 8.0 以降対応、オフラインで動作します。

## 機能

- **通常**：81枚の山札から開始。SET がなければ3枚追加し、山札と盤面の SET が尽きると終了。
- **無限練習**：常に SET のある12枚。正解すると3枚補充。
- **あと1枚**：お題の2枚に合うカードを6・12・18候補から選択。正解に近い候補を優先。
- **自由回答**：候補を見ず、個数・形・色・塗りを指定して回答。
- ヒント、スキップ、盤面・スコア・途中入力の保存。
- Nord / Rosé Pine / カスタム3色。外枠は透明、カードは半透明。
- カードの縦横比を維持。Android 12以降では段数とウィジェットサイズに合わせて配置。

SET with friends に接続しない、独立した1人用練習アプリです。公式画像素材は使用せず、カードは Canvas で描画します。誤答での減点はありません。

## 使い方

アプリを起動して「ホーム画面に追加」、またはホーム画面を長押し → ウィジェット → SET Pocket。4×4程度から配置してください。
ウィジェット上部の文字をタップすると設定画面が開きます。
配色は保存すると即時反映。モード・難易度は保存後、ウィジェットの「新規」または「次へ」で適用します。

カードの色・形・個数・塗りが、それぞれ「全部同じ」か「全部異なる」3枚で SET です。2枚から残り1枚を選ぶ練習では、正解後に自動で次の問題へ進みます。

## Android Studio / Gradle で開発

必要環境：JDK 17、Android SDK Platform 35 / Build Tools 35.0.0。
Gradle 8.11.1、Android Gradle Plugin 8.9.1、Kotlin 2.0.20 を使用します。

1. Android Studio でリポジトリを開きます。
2. SDK を用意し、必要なら `local.properties` に `sdk.dir=/path/to/android-sdk` を指定します。
3. テストと APK のビルド：

```sh
./gradlew testDebugUnitTest assembleDebug
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。
GitHub Actions でも同じコマンドを実行し、APK をビルド成果物として保存します。

## 構成

| ファイル | 役割 |
|---|---|
| `Game.kt` | Android に依存しないルール、ゲーム状態、問題生成 |
| `RulesTest.kt` | 判定・カード保存則・終了条件・練習モードのテスト |
| `SetWidget.kt` | RemoteViews、タップ処理、保存、サイズ調整 |
| `CardArt.kt` | カード描画 |
| `Preferences.kt` | 配色と次のゲームの設定 |
| `MainActivity.kt` | 設定画面、ウィジェット追加 |
| `res/layout*` | ウィジェット配置 |
| `scripts/build-direct.sh` | 制限された環境向けの直接ビルド手順 |

## 検証とビルド履歴

9件の JVM テスト：全85,320組の SET 判定、全3,240組の完成カード、2,000回の無限補充、300ゲームの通常モード完走、候補数ごとの正答一意性、自由回答などを検証します。

これまで配布した APK は、Kotlin コンパイラ・ECJ・AAPT2・D8・zipalign・apksigner を使って直接ビルドしました。再現用スクリプトの先頭に必要な環境変数を記載しています。初期版は利用者の実機で動作を確認済み。最新追加画面の実機確認は別途必要です。
GitHub Actions の実行結果は、リポジトリへのアップロード後に確認してください。

## 署名

署名鍵とビルド成果物は Git に含めません。通常の開発用ビルドでは Android の標準 debug 署名を使います。
既存の `dev-signing/debug.keystore` が手元にある場合のみ、その鍵を使用します。
直接ビルドでは鍵がなければ `build/direct/debug.keystore` を生成します。
以前配布した APK を上書き更新するには、同じ署名鍵が必要です。別の鍵でビルドした場合は、別の端末・エミュレーターで試すか、既存アプリを削除してから入れ直します（削除すると保存状態も消えます）。

変更履歴は [CHANGELOG.md](CHANGELOG.md) を参照してください。
